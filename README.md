# 📚 Learning Log

SIerで8年の経験があります。4年目くらいまではテスターやインフラ構築、手順書作成、
簡単なテストツールの作成、開発のサブリーダーなど、技術寄りの業務にも携わっていました。
5年目くらいからはプロジェクトリーダーとして、技術そのものよりも進捗管理・案件管理が中心になり、
コーディングやインフラ設計を自分の手で動かす機会は減っています。

これからのAI時代、設計や実装の妥当性を自分でも判断できるように、
また開発者と対等に会話し、判断ポイントを押さえられるようになるために、
日々の学びをここに記録していきます。

コードを書いた成果物は、アプリ単位で別リポジトリに整理予定です。
